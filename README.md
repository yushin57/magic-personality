# 識人魔法心理測驗

5 組直覺式選擇（8選4 → 4選2 → 2選1），計算出使用者在「果斷/掌控/分析/事務/創意/感覺/理想/人際」八維特質上的原始分數，並歸納成外向內向、理性感性、行動思考、理智開創組織情感等對比數據。結果頁只顯示姓名、測驗時間與原始數據表格，方便客戶截圖留存，供日後再測時比對變化。

純靜態網站，無後端、無資料庫，部署在 GitHub Pages：https://yushin57.github.io/magic-personality/

## 檔案結構

- `index.html` — 頁面結構、meta tags（含社群分享用的 Open Graph 標籤）
- `style.css` — 樣式（神秘命理風：深紫＋金色調）
- `quiz-data.js` — 5 組題目內容（純資料，改題目不用動邏輯）
- `script.js` — 渲染、計分、結果呈現、分享/重測功能
- `og-image.png` — 社群分享預覽圖（1200×630）

## 本機預覽

```bash
python3 -m http.server 8000
# 開瀏覽器 http://localhost:8000
```

## 修改題目

編輯 `quiz-data.js` 的 `sets`：5 組題目，每組 8 個選項，每個選項對應一個 `trait`（必須是這 8 個之一：果斷/掌控/分析/事務/創意/感覺/理想/人際）。

## 部署時記得：更新快取版本號

`index.html` 裡 `style.css`/`quiz-data.js`/`script.js` 的連結都帶了 `?v=20261017c` 這種版本字串。
**每次改完這三個檔案要部署時，記得把這個版本號改成新的字串**（例如當天日期），
否則瀏覽器可能會繼續用快取的舊版本，使用者看到的畫面/功能不會更新
（GitHub Pages 本身不提供自訂 cache header 的方式，只能用這招強制瀏覽器重新抓檔案）。
